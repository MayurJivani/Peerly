Peer-to-peer file transfer in the browser. One person shares an id, the other
types it, and the file goes straight between the two tabs over WebRTC. No
upload, no server holding the bytes, no size ceiling imposed by somebody's free
tier.

React and Vite on the front, [PeerJS](https://peerjs.com) for the connection.

```bash
npm install
npm run dev
```
